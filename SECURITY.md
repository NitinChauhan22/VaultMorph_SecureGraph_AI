# Security Policy

## Reporting a vulnerability

If you believe you've found a security vulnerability in SecureGraph AI, please report it
privately rather than opening a public issue.

- Email: contact@vaultmorph.org (subject line: "Security Report — SecureGraph AI")
- Please include: affected version, a description of the issue, and steps to reproduce.

We aim to acknowledge reports within 48 hours. Please allow time for a fix to be released
before any public disclosure.

## Supported versions

Only the latest released version of SecureGraph AI Desktop Community Edition is supported
with security fixes.
